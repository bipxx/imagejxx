# Indexed numeric conversion and filter dispatch

The p07b checkpoint qualifies native indexed numeric conversion against ImageJ
1.54r. It applies through the C++ core, Python interface, native workflows and the
shared Dear ImGui standard Image > Type review. No runtime dependency was added.

`classify_indexed_palette` is available in C++ and Python. It distinguishes color,
pseudocolor, inverted grayscale and genuine indexed color using the actual map
size. A short grayscale map differs from a full grayscale ramp; the built-in
3-3-2 RGB map also has ImageJ's special pseudocolor classification.

| Operation | Qualified behavior |
| --- | --- |
| Indexed byte to 8-bit, single plane | Pseudocolor retains indices and receives a grayscale LUT; other palettes render their displayed colors to grayscale. |
| Indexed byte stack to 8-bit | Genuine indexed color renders to grayscale. Pseudocolor retains indices with a grayscale LUT. Short grayscale maps retain indices and palette. |
| Indexed byte to 16-bit or float | Genuine indexed color requires conversion to 8-bit grayscale first. Accepted grayscale/pseudocolor input retains numeric codes and the base LUT. 16-bit clears the display range; float retains it. |
| Gaussian blur or median | Process byte indices directly and retain the palette. |
| RGB/RGBA to scalar with old indexed provenance | Retire the active indexed definition, preserving it under `imagejxx.retired_indexed_palette`. |

Rendering uses the supported current display palette and range; the stored palette
is the fallback. Weighted RGB conversion uses the existing normalized weight
options. A fixed 256-entry lookup avoids allocating a plane-sized RGB intermediate.
Resource admission includes conservative palette/lookup workspace, and remapping
honors cancellation checkpoints.

Pixel data, palette definition, display changes and conversion provenance publish
together. Palette-only 8-bit conversions still create the paired edit. Both hosts
retain that metadata through legacy adapters, recording and Undo/Redo. Complete
T/C/Z conversion retains calibration, selections, ROIs, planar annotations and
view state. Unsupported known-palette conversions fail before source reads when
the palette is already known. A palette generated by an earlier workflow step is
data dependent: execution validates its actual classification before publication;
a rejected workflow leaves the original owner unchanged. The private deferred
descriptor cannot be forged through user metadata.

The fixture [indexed-type-imagej154r.json](../tests/fixtures/indexed-type-imagej154r.json)
contains 360 independently captured cases over nine palettes, single planes and
three-plane stacks, default/limited ranges, weighted/unweighted conversion and
five operations. It records upstream source, runtime, driver and archive hashes.
The capture script is [capture_indexed_type_reference.py](../scripts/capture_indexed_type_reference.py).
Upstream classes are reference tooling and are not installed with the product.

Validation passes 373 new Python cases within 2,076 source and 2,076 installed
checks, 23 Windows native suites, seven fresh Linux native suites and a headless
installed C++ SDK consumer. Raw input evidence exercises the ordinary type menu,
8-bit then float conversion, recording and two-step palette Undo/Redo in both
source and installed C++/Python hosts. Evidence and cleanup receipts are indexed by
`build/p07b-indexed-dispatch001/indexed-dispatch-handoff001.json`.

The next packets remain deliberately scoped:

1. Audit every remaining indexed filter's ImageJ eligibility and palette policy,
   beginning with dtype-changing rank/variance and edge operations. Qualify
   standalone and chained workflows, partial targets, display pairing and history.
2. Capture active-threshold and channel-display conversion behavior. These indexed
   numeric inputs currently fail explicitly; expand to RGB first where needed.
3. Implement true indexed TIFF/PNG encoding and interpretation, checking files in
   an independent reader rather than relying only on metadata round trips.
4. Continue the broader gap inventory and release/platform checks. The historical
   histogram auto-contrast source fingerprint gate still needs requalification.

This checkpoint does not certify arbitrary indexed filters, external file formats
or the entire ImageJ/Fiji feature family. All99 remains 42 in progress, 57 open,
zero complete; the last full source release remains Source901.
