### Capability boundary for this increment

Safe scientific operations are native session Save/Open, close, supported view
position/cameras and explicitly qualified display-only controls. Global New/Open,
Preferences and job inspection remain available under their existing contracts.
Legacy pixel/selection/ROI mutations, clipboard transfer, derived images,
measurement/results, processing/preview/Apply/replay, facade undo/redo and v2
export are unsupported here. Refuse unknown document commands by default;
validate explicit document IDs and all multi-source inputs before side effects.
Native owner transactions remain independently usable through the core API.
P06d1 supplies the later scientific editor adapters rather than relaxing this
boundary incidentally.

Implement and test one shared scientific read adapter before qualifying desktop
admission. The held admission change is not a b1 or b2 pass. Preserve
typed/native storage and the current content-policy limits.
Derive Z count and current plane from Dataset shape and native display position;
do not eagerly copy T*C*Z planes into a second desktop owner.

Pass T/C into XY/XZ/YZ extraction and automatic display-range computation. Include
them in texture/readback/range cache identity, including preview source and
generation where applicable. A C/T switch at unchanged spatial coordinates must
refresh every visible plane; a camera-only change must not masquerade as a data
edit. Reuse existing revision and input-focus behavior.

The facade/header, orthogonal adapter and native/SDK assertions are held as
listed above. Root adopts them with Window integration; a separate owner finishes
the independent UI reader. Do not assign the same producer implementation again.
Freeze exact files and shared ownership before editing or running gates.

### b2: controls, guarded admission and persistence

Expose one-based C/T/Z controls and exact current indices using native
DisplayState. Preserve existing pointer, wheel, keyboard, crosshair and linked
or independent camera behavior. Core/Python indices remain zero-based. Include
calibrated spatial coordinates and time position without changing source data.

Before admission, classify every reachable command as scientific-safe or
unsupported for this slice. Enforce the same capability rule at the command/API
dispatch boundary and in visible controls; disabled buttons alone cannot stop a
programmatic call. Audit filters/previews, clipboard, selection and ROI changes,
stack and geometry commands, conversion, calculator, undo/redo/replay and legacy
export. P06d1 owns later scientific processing targets; preserve working eager-Z
behavior. Do not claim scientific edit/undo until that adapter is qualified.

Stage a complete session before adoption. Mixed unsupported sources or state
must leave membership, active document, results, workflow, preferences and
extensions unchanged. Retain lazy-source and unsupported nonfinite/Fourier
guards. Native scientific session Save/Open must preserve axes, current C/T/Z,
cameras and opaque state; unsupported v2 export must preserve its destination.
