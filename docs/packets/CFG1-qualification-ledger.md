Python. Four CPP recipes pass through the genuine selected CI capture envelope;
the same reader session launches four fresh Python counterparts through the
committed harness. All required selected cases pass without failures/errors/skips.
This is selected local CI-profile coverage, not complete hosted/release CI.

The Python child pins and rechecks the installed `imagejxx`, `_native`, `_desktop`
and public `imagejxx.ui.app` bytes, including supplied desktop/wrapper hash
requirements. Timeout cleanup always targets the known owned launch tree even
if runtime metadata is incomplete; invalid metadata never supplies a kill PID.
The real timeout tests verify the owned interpreter and its leaf stop before
scratch retirement. No product process is left running by the qualified checks.

## Corrections and evidence retention

The first C runner assumed the Windows virtual-environment launcher PID was the
interpreter PID. The observer now binds actual PID/parent lineage; failed reports
and source preimages remain retained. The first independent reader assumed
LSB-first mask packing; the unchanged native contract is MSB-first. The raw four
mask literals never changed. Its failure XML and reader preimage are retained;
the current reader uses independent literal packed encodings.

Read-only review strengthened required UI sequences, draft/Defaults saved values,
full owner invariants, wrapper identity and timeout cleanup. All affected current
readers/cleanup paths were rerun; product inputs did not change. A retained Linux
SDK executable copy initially lacked its execute bit. Its original SDK run had
passed; restoring the owned file's mode preserved binary bytes, and final
readback of current-CI files passed. The failed attempt remains available in its
verified archive; it is not counted as a success.

One active compiler cache/runtime per platform was reused. SDK consumer caches
were stripped after identity retention, not archived. Every terminal UI/API/tool
scratch directory was losslessly compressed, member/hash verified and removed.
Native fixture files and compile diagnostics were similarly retained; no retired
`build/`, new environment, worktree or whole-SDK archive was created.
Prior P13i GUI installation slots were overwritten by CFG1; old binary bytes are
unavailable unless separately retained. Original P13i source/capture evidence and
identities remain unchanged; current receipts record that availability change.
