## Versioned state and persistence

Recognize only `channel_display` objects containing
`schema="imagejxx.channel-display"` and integer `version=1`. The exact state fields are:

```json
{"schema":"imagejxx.channel-display","version":1,"mode":"composite",
 "channels":[{"visible":true,"range":[0,255],"lut":{"name":"Red"}}]}
```

Modes are `color`, `grayscale`, `composite`; channel array index is native C and
its length equals the dataset's C extent. `DisplayState.c` is the active channel,
without a duplicate selected index. Ranges are finite numeric pairs under the
frozen degenerate-range policy; nondegenerate ranges are strictly increasing.
LUT is exactly a supported named palette or `{"table":[...256 RGB byte rows...]}`;
reject mixed forms, unknown fields, booleans as numbers and invalid bytes.
The63+9 entry observations and frozen numerical policy above define the
implemented defaults and equal-endpoint behavior; do not recapture them merely
to prepare desktop integration. A literal[0,0] range remains explicit.
Absent state preserves current legacy viewing; enabling the panel must not
silently replace an existing explicit range or custom LUT.
For flat `display_range`/`lut`/`custom_lut` coexisting with channel state, first
enable inherits explicitly stored legacy range/LUT into each C; absent explicit
legacy values use the frozen native defaults. Inspect native properties rather
than facade-injected defaults. Convert an unsupported legacy named LUT to an
exact256-row table or refuse enable atomically. Recognized state then controls
both renderers and qualified range consumers; channel edits preserve the flat
fields. Disable/removal restores those unchanged fields, including C1/eager-Z.
No adapter may silently delete or substitute a display field.

P06a already transports opaque version1 and version37 objects. Preserve those,
unknown schemas and future versions losslessly in native sessions; a desktop may
refuse unsupported interpretation atomically. Generic metadata transport must
not reinterpret every version1 object as this schema. Keep V3 framing unchanged.
Known state validates C counts against geometry; a geometry edit requires an
explicit display remap or refusal before publication, never truncation.

Display edits use native `set_display`: preserve immutable pixels, data history,
calibration, ROI records and existing dirty/save semantics. Save/Open retains the
complete state. Audit duplicated display-key projections in `document.cpp`,
`session_metadata.cpp`, Python detached/marked adapters and Window display
publication: they currently enumerate range/LUT/custom-LUT/threshold only.
Preserve channel state in each qualified path or refuse that adapter explicitly;
legacy V2/detached export must never silently discard it.

Mode/visibility/range/LUT/Reset range changes use the implemented versioned
[native action contract](../../include/imagejxx/channel_display_command.hpp).
Set/Disable inspect metadata only; Reset range reads live captured T/Z and records
the resolved state. Strict replay binds owner, Pixels+Metadata revisions,
shape/type/sample policy and never recomputes a range. Explicit full rebind
validates the original record first and recomputes only for a requested Reset.
Window must reserve recording output before display publication, appending one
normalized record only on success when recording is on. Recording/replay
preserves existing display dirty/save semantics and creates no pixel-history
entry. Persisted display state and action records remain distinct schemas.

Audit range consumers as well as transport. `Window::operationDefaults` currently
reads one flat `display_range`; a per-C display range must not silently fall back
to that value during display-range conversion/export. Introduce one source-bound
effective-range lookup shared by rendering/Reset range and each qualified consumer.
Freeze all-plane/per-C conversion policy separately; keep scientific conversion
guarded until its adapter is qualified, and preserve existing eager-Z defaults.

## Pixels, samples, previews and bounded caches

C selects scientific channels; S remains interleaved components. First qualify
three-mode composition for S=1, UInt8/UInt16/Float32 scalar channels. Preserve
existing Float64 and S=3/S=4 viewing without claiming upstream scalar composite
support; unsupported composite requests refuse before changing display state.
Quiet-NaN rendering retains the established explicit policy and needs dedicated
composition assertions. Above8 channels retain navigation/Color viewing under
the frozen requested-composite fallback; strict stored noncanonical composite
state is rejected. Do not introduce a silent cap.

Stream contributing channel planes into one RGB accumulator and bounded mapping
scratch. Never materialize a TCZ volume or allocate one complete copy per channel.
Resolve Reset range from each channel's **live** current XY plane at captured T/Z, then
publish all requested explicit ranges together. Apply annotations once after
composition under P06b's active-C positioned XY policy; no XY geometry on XZ/YZ.
The position-aware renderer uses the actual final T/C/Z, not inferred metadata:
overlay `t`, `c`, `z` and legacy `slice_index` are independent integer constraints.
Absent/null fields are wildcards; zero is an exact native coordinate. If both
Z fields exist, both must match. Unsupported position values are not coerced
into a visible coordinate. Stored opaque overlay records/order remain unchanged;
context-free legacy rendering overloads retain their existing behavior.

Manual threshold is a separate nondestructive display state. Use live active-C
raw samples once after composition in ordinary/linked XY, only when that C
contributes and saved T/C/Z matches. Never tint from a C excluded by the current
composition mode or from a non-active C, or project XY threshold onto XZ/YZ. Preserve threshold metadata and
qualify ordinary/XYZ agreement under this frozen policy; unsupported combinations
refuse atomically rather than silently changing it.

Choose Gaussian live/staged pixels separately for every contributing C using its
retained target at current T/Z. Active-C containment alone is insufficient when
another visible channel owns the preview. Preserve full Apply capture, live
auto-range, source-tab cancellation and exact preview generation ownership.
Factor a retained per-position live/staged source selector with provenance;
choosing one whole transient-versus-live Dataset from active-C containment is
insufficient. Share that selector between ordinary and linked rendering without
materializing a volume or retaining borrowed target/snapshot references.
Preserve P06d1's qualified navigation-Z gating: test leaving the captured preview
plane and returning, and identify exactly which XZ/YZ source-Z strips use staged
pixels for each contributing C. A per-strip selector must not silently change
the qualified crosshair-Z policy. Any deliberate change requires a named policy
and new affected expectations before integration.
Cache keys include owner/live data identity and revisions, shape/sample policy,
mode, active C where relevant, contributing channels and their range/LUT state,
T/Z or linked fixed coordinate, plus per-channel preview provenance/generation.
Ordinary and linked readbacks must report those actual sources and effective ranges.
