## Record and behavior to settle

### Resolved implementation constraints

Retain the framed-zlib format family with a new version3 marker and a checked
declared uncompressed length. One compressed document needs no ZIP dependency.
Use the existing private JSON codec and strict parsing, with duplicate-key,
depth/count, encoded-length and checked dimension/payload limits before DOM and
pixel allocation. Treat trailing compressed data and mismatched lengths as
errors. Freeze concrete default limits and schema keys with the public interface.

Separate declared `PixelType` from storage encoding. Native finite eager storage
can retain UInt8-tagged values `{-1,.5,300}` or Float32-tagged `1+2^-40`; primitive
packing would lose currently admitted data. Version3 therefore preserves exact
binary64 backing samples using explicit little-endian Float64 storage, alongside
the declared type and content policy. Use existing quiet-NaN bit helpers for its
admitted Float32 policy. A future compact primitive encoding must prove lossless
storage; it is not required to establish the scientific codec.

The exclusive-create/owned-cleanup/write/flush/replace RAII was extracted from
`src/native/preferences.cpp` into a core-private helper. Desktop `writeBytes`
retains its legacy scope. Sessions preserve the P04a failure semantics and
require an existing parent directory. Reviewed zlib1.3.1 compression sources are
privately source-distributed with exact fingerprints and prefixed symbols, so
the core and installed SDK need no external zlib discovery or new runtime DLL.
The desktop keeps its reviewed external codec dependencies.

Native metadata helpers remain reusable, but `view_json`/`parse_view` omit T/C
and `wire_metadata` emits Z-only ROI positions; the scientific record must encode
native T/C/Z directly. Preserve previous selections outside the current canvas,
packed-mask tail bits and optional-position absence. Preserve existing eager-Z
Fourier state; reject scientific Fourier combinations before save until the
model defines their association. Loaded owners receive fresh identities, clean
state and empty history, with recorded actions preserved under explicit replay
rebinding. Save publication marks only the successful captured snapshot saved.

### Complete record obligations

Use a new explicitly versioned record with named TCZYXS dimensions, pixel type,
sample interpretation, deterministic plane ordering and exact typed payloads.
Keep scientific C independent of RGB/RGBA S. Preserve singleton axes rather than
inferring them from array rank. State byte order and supported content policies;
verify exact stored values/bits for admitted data. Any newly supported nonfinite
content policy requires an explicit contract and cannot silently broaden desktop
admission.

Persist spatial/time calibration and native geometry, document metadata,
current T/C/Z and cameras, global display range/LUT/manual threshold, selection,
saved ROIs/positions, styles and overlays under the current model's policies.
Preserve existing optional Fourier/session extensions or reject unsupported
scientific combinations before save. Settle a versioned per-channel-display
extension point now; P06c owns its rendering/UI and complete behavior. Declare
unknown-field/version handling and ensure neither frontend silently drops state.

The [format contract](../SESSION_FORMAT.md) reserves
`documents[i].display.properties.channel_display` with a producer's integer
`version` discriminator. P06a transports it opaquely, including future versions;
P06c defines interpretation and validation. Independent API/SDK cases name
this location and passed typed preservation, including future-version payloads.
Session-root `extensions` remains opaque metadata, without channel ownership.
V3 structural keys
are strict; unknown structural keys fail. Unknown content in declared metadata
extension containers is preserved within scalar/depth/size limits. P06c must
consume the agreed native display contract rather than infer channel ownership
from root metadata. Do not claim composite behavior from opaque preservation.

Map v2 [Z,]YXS to explicit T=C=1 while preserving its sample interpretation,
metadata, legacy defaults and strict marked-state semantics. Preserve read
compatibility and public adapters; scientific output must never masquerade as
v2. Explicit legacy export may accept only representable state and must reject
lossy conversion. Declare whether live revisions, identity, clean/dirty state,
history and recorded actions are restored or reinitialized; preserve existing
reopen behavior unless an explicit migration changes it.

Save an immutable captured snapshot, stage bytes before replacement, and retain
current temporary-file/atomic-replace guarantees. A concurrent edit cannot be
marked saved by an older capture. Fully validate loads before owner publication.
Validate dimension products, payload sizes, member paths/counts, duplicates,
truncation, missing data and allocation/decompression bounds before materializing
untrusted records. Failed/canceled save/load leaves documents, history and the
previous destination unchanged. Capture/serialization must preserve old readers'
metadata-only allocation independence where those APIs do not request pixels.

External/lazy source locators, missing-source recovery, virtual-source streaming,
scientific format codecs and global resource accounting remain required later
children. This packet's eager policy must reject unsupported sources explicitly.

binary64 values; Python round-trips inspect independent wire bytes as NumPy
