## Compatibility, provenance and cleanup

Native owner review confirms the accounting seams: direct prepare receives
`max_target_mask_bytes`; Application submission adds the serial mask peak to
its existing image/result terms; legacy Preview and synchronous/asynchronous
Apply share `L-B-E`; pooled mask subtracts owned histogram/storage terms and
pooled display first deducts its additional analysis storage. Workflow preflight
uses `max(retained,captured floor)+serial peak`; panel prefix/image preview use
half-cap and complete Run deducts its actual record bytes once. Batch deducts
retained/session/statistics phase storage and tightens both workflow caps.
The batch-specific proof above closes the missing focused caller boundary found
by that review. Legacy eager frame lookup and batch file load precede their
documented gates, so they receive no new lazy-source/no-I/O claim.

- NativePathV4, authored workflow V8 and session V5 remain unchanged. Runtime
  byte limits are additive; default behavior and strict Python size validation
  are checked. Matching rebuilt C++ headers/libraries are required.
- Manual threshold V3 is an additive direct-command record for active native
  paths. V1/V2 remain closed and direct strict replay/rebind is checked. The
  [explicit AllZ compatibility decision](../parity/reviews/p13i-path-filter001/manual-threshold-compatibility.json)
  preserves the pre-change failing assertion/source and its replacement proof.
- No new third-party dependency was incorporated. Reviewed commercial inventory
  checks pass for the actual declared/resolved graphs. Windows includes build,
  desktop and reviewed TIFF closure; Linux checks runtime/io/test/desktop.
  The uninstalled Linux optional Python wheel build-backend graph remains outside
  this scoped result. The failed earlier invocation is retained, not a pass.
- Original assertions and fixture fingerprints are preserved; no new exclusion
  was added. The existing scientific-owner exclusion remains explicit.
- One cache/runtime per platform was reused. Terminal chunk scratch was removed
  only after archive/member verification; SDK consumer caches were stripped with
  identity receipts. Whole SDKs/environments/caches were not archived. The retired
  `build/` generations were not recreated. Superseded capture and unused Qt SDK
  retirement records preserve identity/availability changes.
