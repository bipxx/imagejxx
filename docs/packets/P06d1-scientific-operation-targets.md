  membership before entering the lane. A malformed typed API request leaves
  existing panel/job state unchanged; UI text follows the draft policy above.
  Keep the existing release-first lane contract: supersede/release the prior

  error, release reservations and preserve pixels, history, results, recording,
  workflow and clipboard. Do not promise old-preview retention or add a second
  preflight/reservation API solely for this child. Qualify this handoff before
  integrating target controls.

  under its frozen source/options/ROI and publishes once. Untargeted plane
  identity, axes, S layout, calibration, annotations and metadata remain intact.
- Preserve native no-op behavior: sigma zero, all-empty masks or numerically
  identical output creates no pixel history entry or dirty transition. A changed
  accepted Apply creates exactly one undo entry regardless of plane count.
  Preserve the existing Gaussian accepted-command recording policy: when
  recording is enabled, successful publication appends the accepted command
  even for a pixel no-op. Cancellation or failed publication appends nothing.

  history path. Call the native controller directly and refresh facade/XYZ

  published native edits that the admitted owner can contain. If a history state

  dependencies remain native: whole-plane depends on pixels/metadata; ROI
  policies also depend on selection. Retain the panel's existing stricter

  A real data conflict, close, source-tab change or replaced request releases

  canceled, cancellation before publication yields no edit/record, and once
